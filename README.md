# Be My Pizza

Единая кодовая база клиентского приложения Be My Pizza: **React + TypeScript + Vite + Capacitor** для Web (mobile/desktop), Android и iOS.

## Статус
- Начало разработки: 21 ноября 2026.
- Репозиторий публичный по решению владельца.
- Технический фундамент создаётся; страницы ещё не утверждены.
- YumaPOS — возможная CRM/POS-интеграция, **не подтверждена**.
- Пока разрабатываем локально и в GitHub, без Render, REG.RU и серверов.

## Принципы
- Mobile-first, затем desktop без копирования логики.
- Одна кодовая база для Web/iOS/Android.
- Изоляция API: сегодня mock, позже адаптер backend / YumaPOS.
- Каждая страница проходит отдельное утверждение заказчиком.
- Не выдумывать цены, акции, условия доставки и платежей.
- После каждого значимого действия обновлять `docs/BE_MY_PIZZA_MASTER_CONTEXT.md`.
