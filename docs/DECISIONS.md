# Architecture Decision Log — Be My Pizza

## 2026-11-21 — Mobile first, single frontend
**Accepted.** Один React + TypeScript + Vite frontend. Responsive desktop в тех же компонентах, Android/iOS через Capacitor. Без отдельных копий бизнес-логики.

## 2026-11-21 — CRM/POS undecided
**Pending.** YumaPOS вероятна, но не подтверждена. API за абстракцией CatalogGateway/OrdersGateway. На клиенте только mock, без секретов.

## 2026-11-21 — No cloud yet
**Accepted.** Разработка локально и в GitHub. Позднее пилот на Render, предположительно production на REG.RU. Никакой ранней конфигурации серверов.

## 2026-11-21 — Public repository
**Accepted by owner.** Репозиторий Ryt1nger/Be-My-Pizza публичный. Не публиковать ключи/секреты/личные данные.

## 2026-11-21 — Page approval
**Accepted.** Одну страницу за раз; статус «утверждено» только по прямому подтверждению владельца.

## 2026-11-21 — Brand/logo
Владелец прислал изображение оригинального логотипа. В текущем коде временная текстовая заглушка, пока не перенесён исходный файл. Не подменять логотип чужим.

## 2026-11-21 — Catalog
15 фотографий сопоставлено по скриншотам старого меню; названия утверждены владельцем. Цены/составы/варианты не утверждены; хранить null/пустые массивы.
